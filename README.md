# Plant_Manager_1

Phase 1 foundation for Plant Manager using Next.js + Supabase.

## Local setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Copy env vars:
   ```bash
   cp .env.example .env.local
   ```
3. Run development server:
   ```bash
   npm run dev
   ```
4. Run tests:
   ```bash
   npm test
   ```
5. Build:
   ```bash
   npm run build
   ```

## Included in Phase 1
- CRUD pages for projects, suppliers, plants, and daily logs.
- Dashboard totals.
- Centralized hour calculations and unit tests.
- Supabase schema migration and seed file.
